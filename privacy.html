Privacy Policy – JARVIS Social

Last updated: 26 October 2026

1. Scope

This policy covers the JARVIS Social tool (Google Cloud project “jarvissocialmedia” and Meta app “JARVIS Social”) and this website.

2. Controller and contact

The controller is the operator of the channels Orbit Workshop and Odd Little Shapes. Contact: jarvis.socialmedia16@gmail.com.

3. Who uses the tool

JARVIS Social is a private tool. Only the operator signs in, and only with his own Google, Facebook and Instagram accounts. It does not process data of other users.

4. Google user data

The tool requests these YouTube Data API scopes:

  • youtube.upload: upload the operator's own videos to his own channels;
  • youtube.readonly: confirm the connected channel (ID and title) and read back the status of the operator's uploads;
  • youtube.force-ssl: only if the operator enables it, to delete his own uploads.

The data is used only for these purposes. It is not sold, not shared with third parties, not used for advertising, and not used to develop, improve or train generalized artificial intelligence or machine learning models.

JARVIS Social's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

5. Instagram and Facebook data

Through the Meta Graph API the tool reads the operator's own Facebook Pages and linked Instagram accounts (ID and username) and publishes the operator's own videos on them. The same restrictions as in section 4 apply.

6. Storage and security

Access tokens and account identifiers are stored only on the operator's own computer, in files that only the operator's user account can read. The tool runs no server of its own and stores no data in any cloud service.

7. Revoking access and deletion

Google access can be revoked at any time at myaccount.google.com/permissions, Meta access in the Facebook settings under “Business integrations”. Revoking access invalidates the stored tokens; the operator also deletes the local token files.

8. This website

This website is hosted on GitHub Pages by GitHub, Inc. When the site is visited, GitHub may process technical data such as the IP address to deliver the site and keep it secure; see the GitHub General Privacy Statement. The site itself sets no cookies and uses no tracking or analytics.
